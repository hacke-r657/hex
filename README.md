# HEX Survival

A playable first-person survival prototype made with Python and Ursina.

## Run

```bash
python -m pip install ursina
python main.py
```

## Controls

- `WASD` move, `Shift` sprint, `Ctrl` crouch, `Space` jump
- `1-6` select hotbar item
- `E` collect, `C` craft, `H` eat
- `Q` melee attack, `F` fire an arrow
- `B` build wall, `G` build floor, `N` build campfire
- `R` toggle rain, `T` toggle night vision
- `F5` save, `Esc` pause/resume

The game creates `save_data.json` beside `main.py` after playing. Delete that file to reset the save.
